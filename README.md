# XenOmen

XenOmen provides real-time data processing and auto-scaling for distributed systems, leveraging an adaptive server framework.

With XenOmen, you get a lightweight tool that stays out of your way.

**What you get**

## Installation

1. Clone the repository: `git clone https://github.com/irenascent/XenOmen.git`
2. `cd XenOmen`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
